2. Посетители, данные и цели

Сайт предназначен для посетителей, интересующихся услугами клиники. На этом сайте нет собственных форм заявки и загрузки медицинских документов. При открытии страниц хостинг получает технические данные запроса: IP-адрес, время, адрес страницы и сведения о браузере. Цель — показать страницу и обеспечить работу сайта. Оператор не получает через сайт паспортные данные или сведения о здоровье.

Если посетитель отдельно включает карту или отзывы, браузер соединяется с Яндексом и передаёт ему IP-адрес, технические сведения и, при отдельном разрешении для маршрута, координаты. Цели — показать карту, отзывы либо построить маршрут. Координаты не записываются в базу этого сайта.

Сейчас Яндекс Метрика, иные аналитические счётчики и рекламные пиксели на сайте не подключены.

Технические запросы необходимы для выдачи страниц сайта. Необязательные виджеты Яндекса и геолокация запускаются только после отдельного действия и согласия посетителя. Если аналитика будет включена, согласие на неё запрашивается отдельно. Чтение сайта не означает согласия на необязательные функции. Условия и текст согласий приведены на отдельной странице.

В рамках этих целей могут выполняться сбор, передача по сети, просмотр, использование и удаление технических данных. Собственные серверные базы заявок, аккаунтов посетителей и медицинских данных на этом сайте не ведутся. Согласие на рекламную рассылку здесь не запрашивается.

Публичная демонстрационная версия сайта размещена на GitHub Pages. Хостинг фиксирует технические запросы посетителей; эта площадка не заявлена как российская инфраструктура для постоянной работы клиники. Перед запуском постоянного сайта место хранения журналов и условия обработки будут проверены и указаны здесь.

Карта и отзывы Яндекса загружаются после разрешения в каждом виджете. Переход к записи в YCLIENTS открывает отдельный сайт; сведения, которые посетитель вводит там, обрабатываются по условиям формы записи. Telegram также открывается только по нажатию ссылки. До клика эти страницы и их встроенные формы не загружаются на данном сайте.

Внешние сервисы обрабатывают полученные ими данные по своим правилам: Яндекс, Telegram. Для демонстрационной версии действуют также правила GitHub. Сведения о cookies и настройках собраны здесь.

5. Сроки, отзыв и защита

Отметки согласия для карты, отзывов и геолокации действуют в текущем открытом виджете и не сохраняются между посещениями. Координаты маршрута используются однократно в браузере и не отправляются на сервер сайта. Решение об аналитике не сохраняется, поскольку счётчик пока не включён. Срок хранения журналов хостинга будет уточнён для постоянного размещения. Сроки хранения данных внешних сервисов определяются их условиями.

Виджет можно закрыть кнопкой под ним, а разрешение на геолокацию удалить в настройках браузера. Если Метрика включена, её разрешение можно изменить через «Настройки аналитики» в подвале. Отзыв не удаляет сведения, уже полученные сторонним сервисом. Вопросы, запросы на доступ, исправление или удаление данных можно направить по контактам в разделе 1. Технические меры сайта включают HTTPS и загрузку внешних виджетов только по выбору посетителя.
