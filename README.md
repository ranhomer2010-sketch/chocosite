# ВШоколаде — сайт клиники в Лобне

Многостраничный сайт с орбитальной навигацией, записью через YCLIENTS,
отзывами и картой Яндекса, которые загружаются только после согласия.
Геолокация для маршрута запрашивается отдельно.

## Включить GitHub Pages

Откройте https://github.com/ranhomer2010-sketch/chocosite/settings/pages

1. Source: **Deploy from a branch**.
2. Branch: **main**, папка **/docs**.
3. Нажмите **Save**.

После публикации: https://ranhomer2010-sketch.github.io/chocosite/

Папка `docs` уже содержит готовую сборку. Первое включение не требует Node.js или команд.

## Редактирование

Требуется Node.js 22.13 или новее.

```sh
npm install
npm run dev
# http://localhost:3000/chocosite/
```

Тексты и цены: `lib/content.ts` и `app/`. Стили: `app/globals.css`.
Фотографии, логотип и локальные шрифты: `public/`.

После изменений выполните `npm run build` и загрузите в репозиторий исходники
вместе с обновлённой папкой `docs`. Сборка создаёт отдельный HTML для каждой страницы.

Путь `/chocosite` задан в `next.config.ts`; при переносе на другой адрес задайте
`NEXT_PUBLIC_BASE_PATH` при сборке. Внутренние ссылки учитывают этот путь.

Сайт не сохраняет координаты и не отправляет их на свой сервер.
Виджеты обращаются к Яндексу только после соответствующего согласия.
Запись открывает внешнюю страницу YCLIENTS.
